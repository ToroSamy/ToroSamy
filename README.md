I am a Full-Stack Developer & Systems Enthusiast who loves exploring the boundaries between high-level applications and low-level hardware. My expertise spans across modern web ecosystems, backend distributed architectures, robotics navigation, and game modding/server ecosystems.

- 🎮 **Game Dev & Modding:** Experienced in crafting custom **Stardew Valley Mods (C#)** and developing **Minecraft Bukkit/Spigot Plugins (Kotlin/Java)**.
- 🚀 **Robotics & CV:** Specialized in **ROS2 & Navigation2**, LiDAR SLAM (**Point-LIO / Fast-LIO**), and AI-driven computer vision tools for gaming automation.
- 📝 **Blog:** I write about tech, systems, and my dev journey at [torosamy.net](https://www.torosamy.net).
